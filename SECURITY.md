# Security Policy

## Supported Versions

BluePrint ERP is currently in beta. Security fixes are applied to the latest `main` branch only.

| Version | Supported          |
|---------|--------------------|
| latest main | ✅ Yes          |
| older       | ❌ No           |

## Reporting a Vulnerability

We take security bugs seriously. Please DO NOT open a public GitHub issue.

**Email:** legal@blueprint.ae
**Subject:** `[SECURITY] <brief description>`

Please include:
1. Description of the vulnerability
2. Steps to reproduce (proof of concept)
3. Affected versions/commits
4. Potential impact
5. Suggested fix (if any)

### Response timeline

- **Acknowledgement:** within 48 hours
- **Initial assessment:** within 5 business days
- **Fix or mitigation:** depends on severity (critical: 7 days, high: 30 days, medium: 90 days, low: next release)

### Safe harbor

We will not take legal action against researchers who:
- Make a good-faith effort to avoid privacy violations, destruction of data, and interruption of services.
- Report vulnerabilities promptly.
- Do not publicly disclose the vulnerability until a fix is released.
